# Music

Not stored here. The tracks are licensed for use in our videos (YouTube Audio Library), not for
redistribution, so this public repo never holds them.

They live in the private studio repo `b18tuna-beep/designed-otherwise-studio` at `assets/music/`,
with their license lines in `assets/music/LICENSES.md` there. `assemble.yml` reads them through a
read-only sparse checkout with `STUDIO_TOKEN` at run time and never uploads them anywhere.

P1 uses "Dreamscape" (Density & Time) and "Frame-Dragging" (The Grey Room & Density & Time),
both YouTube Audio Library, attribution not required.
